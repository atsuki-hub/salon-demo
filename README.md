# リラクゼーションサロン 予約・経営ダッシュボード デモ

小規模リラクゼーション／マッサージサロン（セラピスト2〜3名想定）向けの、予約管理と経営ダッシュボードを1サイトにまとめた静的Webデモ。クラウドワークス等で受注前に提示する「見せ物」用で、納品時はGAS＋スプレッドシートに載せ替える前提で設計しています。

- 形態: 静的HTML/CSS/JS、ログイン不要、サンプルデータはJSに埋め込み
- 主役: 経営ダッシュボード（指標14種類）。予約管理・顧客フォームは脇役
- データ構造はそのままGAS版のシート構造になります（後述）

## 起動方法

ブラウザで `index.html` を開く、または任意の静的サーバで配信:

```bash
npx serve .
# ターミナルに表示されたURL（例: http://localhost:3000）にアクセス
```

## 画面構成

| 画面 | ファイル | 主な機能 | 想定ユーザー |
|------|----------|----------|--------------|
| 経営ダッシュボード | `index.html` | 指標14種、期間プリセット、セラピストフィルタ、比較表 | サロン経営者 |
| 予約管理 | `reservations.html` | 日／週／月／リスト切替、予約追加・詳細モーダル | サロンスタッフ |
| 顧客向け予約フォーム | `book.html` | 公開予約フォーム。氏名・日時・メニュー・指名選択 | エンドユーザー（HP埋め込み想定） |

`book.html` はサロンのホームページに `<iframe src="book.html">` で埋め込むか、「ご予約はこちら」のリンク先として使う想定。送信された予約は `予定` ステータスで登録され、予約管理画面に反映されます。

## ダッシュボード指標（14種類）

仕様書（`仕様書.txt`）の M1〜M14 に対応。集計対象は原則「ステータス=済」のみ。

| # | 指標 | 概要 |
|---|------|------|
| M1 | 売上推移 | 技術売上＋店販売上の推移。粒度は期間に応じて自動切替 |
| M2 | 客単価 | 技術客単価／総客単価の2枚カード |
| M3 | 店販比率 | 店販売上 ÷ 総売上 |
| M4 | 新規／再来構成 | 件数と構成比 |
| M5 | 90日定着率 | 初来店から90日以内に2回目来店した新規客の割合（月別） |
| M6 | 平均再来周期 | 同一顧客の前回来店からの平均日数 |
| M7 | リピート率 | 通算2回以上来店した顧客の割合（累積・補助） |
| M8 | 失客アラート | 前回来店から90日超の顧客リスト |
| M9 | 指名率 | 指名予約の割合（全体＋セラピスト別） |
| M10 | セラピスト別売上 | ランキング表示 |
| M11 | セラピスト別客単価 | M9と並べて指名と単価の相関を示唆 |
| M12 | 稼働率 | 席稼働率（サロン全体）＋セラピスト別稼働率 |
| M13 | メニュー別売上構成 | カテゴリ別の構成比 |
| M14 | メニュー別 時間あたり売上 | 円／時で予約枠の埋め方を判断 |

### ダッシュボードの主な仕様

- **期間プリセット**: 今月／先月／直近3ヶ月／全期間（6ヶ月）
- **粒度自動切替**: 売上推移は期間に応じて日次（≤1ヶ月）／週次（≤3ヶ月）／月次。日次は曜日付きラベル＋土日強調色
- **セラピストフィルタ**: 全カード・全グラフがその担当者ベースに再計算
- **セラピスト別比較表**: 予約件数／売上／客単価／指名率／リピート率／90日定着率／平均再来周期／稼働率
- **失客アラート閾値**: 90日固定（`settings.churnThresholdDays`）
- **集計中表記**: M5・M6 の直近期間は値が確定しないため「集計中」と明示

## 予約管理画面の主な仕様

- **日ビュー**: タイムグリッド（10:00〜20:00／30分刻み）。横軸セラピスト3名、縦軸時間
- **週ビュー**: 7日間カード表示、セラピスト別ライン色
- **月ビュー**: カレンダー形式。日ごとの件数・売上・予定件数
- 空きコマクリックで予約追加モーダル、既存予約クリックで詳細モーダル
- 重複・営業時間超過バリデーション
- 定休日（火曜）は斜線オーバーレイ
- ステータス: `予定`（青系・モーダルで追加）／`済`／`キャンセル`／`無断`

## サンプルデータ

- **期間**: 2025-12-01 〜 2026-05-31（6ヶ月）
- **規模**: 顧客90人、セラピスト3人、予約 約900件
- **メニュー**: もみほぐし／アロマトリートメント／フットリフレ／ヘッドスパ／ストレッチ整体（計7種、3,300〜12,000円）
- **セラピスト**: 主任1名＋セラピスト2名（勤務時間 7〜8h）
- 顧客ごとに「お気に入りセラピスト」「ロイヤルティ」を設定（リピート率の自然なばらつき）
- 土日は平日より予約多め

> サロン名・顧客氏名・セラピスト氏名・売上数値などはすべて **架空のデモデータ** です。実在の店舗・人物・団体とは一切関係ありません。

再生成:

```bash
node scripts/generate-sample-data.js
```

## 設計上の前提

- **1予約 = 1主メニュー**: カット＋カラーのような複合来店も主メニュー1つで計上。M13（メニュー別売上構成）は近似値。本番納品では会計明細テーブルを別に持てば正確化可能
- **集計対象**: 売上・客単価・稼働率系は「ステータス=済」のみ。キャンセル・無断は除外
- **最新月の未確定**: M5（90日定着率）は直近3ヶ月、M6（平均再来周期）も直近は値が固まらないため「集計中」表記
- **6ヶ月分のデータ**: M5を意味のある形で見せるには初回来店から90日の追跡期間が必要

## GAS納品版への移行

`js/data/*.js` の構造がそのままGASスプレッドシートの5シートに対応します。

| ファイル | シート名 |
|---|---|
| `settings.js` | settings |
| `menus.js` | menus |
| `stylists.js` | stylists（セラピストマスタ） |
| `customers.js` | customers |
| `reservations.js` | reservations |

指標計算ロジック（`js/metrics/*.js`）はGAS Apps Script に移植可能です。
