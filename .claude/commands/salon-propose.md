# Salon Project Proposal Generator

このデモをベースにした副業受注用の提案書を生成します。
クライアントへの初回提案・見積もり・納期計画をまとめます。

## 使い方
```
/salon-propose [クライアント名]
```

## 実行手順

### STEP 1: 情報収集

$ARGUMENTS からクライアント名を取得。
なければ AskUserQuestion で以下を収集:
1. クライアント名（サロン名）
2. クライアントの現状（現在サイトあり/なし、予約管理方法）
3. 要望の優先度（予約管理 / 顧客管理 / 経営分析 / 顧客向け予約フォーム）
4. 想定規模（スタッフ数、月間予約件数）
5. 希望納期（急ぎ/3ヶ月以内/半年以内/未定）
6. 予算感（〜10万/〜30万/〜50万/要相談）

### STEP 2: デモの現状分析

現在のプロジェクトを分析して、提案に含める機能を特定:
- `js/data/` → 管理できるデータ種別
- `index.html` → ダッシュボードのKPI一覧
- `reservations.html` → 予約管理機能
- `book.html` → 顧客向け機能

### STEP 3: 提案書の生成

以下のフォーマットで Markdown 提案書を生成し、`proposal-【クライアント名】.md` として保存:

---

```markdown
# 【サロン名】様 システム開発提案書

作成日: 【今日の日付】
提案者: 【作成者名 - "あなたの名前" としておく】

---

## 1. 提案の背景

【クライアントの現状課題を2〜3文で整理】

例:
> 現在、予約管理をLINEと紙台帳で行っているため、スタッフ間での情報共有に
> 時間がかかり、ダブルブッキングのリスクがあるとのことでした。
> また、売上や顧客データを月次で分析する仕組みがなく、経営判断に時間がかかっています。

---

## 2. 提案するシステム概要

本提案では、以下の3つのモジュールからなるWebシステムを提供します。

### 2-1. 顧客向け予約フォーム
- スマートフォンから24時間予約受付
- メニュー・担当者指名・希望時刻の選択
- 予約確認画面での内容確認
- 定休日・満席時の自動チェック

### 2-2. 予約管理ダッシュボード（スタッフ用）
- 日次タイムグリッド表示（スタッフ別の予約状況を一目で確認）
- 週次・月次カレンダービュー
- 予約の追加・変更・キャンセル処理
- 全予約リスト検索・CSV出力

### 2-3. 経営分析ダッシュボード（オーナー用）
以下のKPIをリアルタイム表示:
- 売上推移（月次/週次/日次グラフ）
- 客単価・店販比率
- 新規/再来比率・90日定着率
- スタイリスト別売上・稼働率・指名率
- 失客アラート（来店が途絶えた顧客の通知）
- キャンセル率・無断キャンセル率
```
