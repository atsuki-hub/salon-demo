# Salon Demo Customizer

クライアントの情報をもとに、このサロンデモを丸ごとカスタマイズします。

## 使い方
```
/salon-customize [クライアント名]
```

引数を省略した場合は、順番に質問します。

## 実行手順

### STEP 1: クライアント情報の収集

$ARGUMENTS にクライアント名が渡された場合はそれを使う。
渡されなかった場合は以下を AskUserQuestion で1問ずつ収集:
1. サロン名（例: Hair Salon Sakura）
2. 業種（美容室 / リラクゼーション / ネイル / エステ / その他）
3. メインカラー（例: #e8a4b8 のような16進コード、または「ピンク系」などの色名）
4. スタッフ名と役職（例: 田中 美咲 / チーフ、鈴木 陽菜 / スタイリスト）
5. 主要メニュー3〜5個（例: カット 60分 5,500円、カラー 90分 8,000円）
6. 定休日（例: 火曜日）
7. 営業時間（例: 10:00〜20:00）

### STEP 2: ファイルの読み込み

以下のファイルをすべて読み込む:
- `js/data/settings.js`
- `js/data/stylists.js`
- `js/data/menus.js`
- `css/style.css` (最初の50行：CSS変数部分)
- `index.html`, `book.html`, `reservations.html`

### STEP 3: カスタマイズの実施

以下を順番に編集:

#### 3-1. settings.js を更新
```js
const SETTINGS = {
  salonName: "【クライアント名】",
  seats: 【席数 デフォルト4】,
  openTime: "【開店時刻】",
  closeTime: "【閉店時刻】",
  closedDays: [【定休曜日の数値 月=1,火=2,水=3,木=4,金=5,土=6,日=0】],
  churnThresholdDays: 90
};
```

#### 3-2. stylists.js を更新
クライアントのスタッフリストで STYLISTS 配列を置き換える。
ID は S001, S002... の連番。workHoursPerDay はデフォルト 8。

#### 3-3. menus.js を更新
クライアントのメニューリストで MENUS 配列を置き換える。
- menuId: M001, M002... の連番
- category: メニューの種類（技術/物販など）
- duration: 分単位
- price: 円単位

#### 3-4. CSS変数（ブランドカラー）を更新
`css/style.css` の `:root` ブロックの `--accent` と `--accent-light` を
クライアントのブランドカラーに合わせて変更。

補色の計算:
- `--accent` = メインカラー（やや暗め・ボタン色）
- `--accent-light` = メインカラーの明るめ版（アクセント）
- ウォームカラー系（ピンク/ベージュ/オレンジ）→ --bg と --border も温かみのある色調に
- クールカラー系（ブルー/グリーン/パープル）→ --bg を薄い同系色に

#### 3-5. HTML のタイトルタグ更新
3ファイルの `<title>` を "【ページ名】| 【サロン名】 デモ" の形式に統一。

#### 3-6. サンプルデータの再生成
`js/data/customers.js` と `js/data/reservations.js` を新スタッフ・新メニューに
合わせて整合性を持つサンプルデータに書き換える（最低6ヶ月分・月30件程度）。

### STEP 4: 動作確認チェックリスト

以下を順番に確認し、問題があれば即修正:
- [ ] `settings.js` の salonName がヘッダーに表示される
- [ ] スタッフ名が予約フォームのプルダウンに反映されている
- [ ] メニューが予約フォームに表示されている  
- [ ] ブランドカラーがヘッダーとボタンに反映されている
- [ ] 定休日が正しく機能している（定休日を選ぶと警告が出る）
- [ ] ダッシュボードのKPIが数値を表示している（0や—でない）

### STEP 5: 完了報告

以下のフォーマットで報告:
```
✅ カスタマイズ完了: 【サロン名】

変更ファイル:
- settings.js (基本情報)
- stylists.js (スタッフ: X名)
- menus.js (メニュー: X種)
- css/style.css (ブランドカラー)
- 全HTMLタイトル

次のステップ:
1. `open index.html` でダッシュボードを確認
2. `open book.html` で予約フォームを確認
3. /salon-audit でUI品質チェックを実行
```

## 注意事項
- サンプルデータは架空の日本人名を使用（個人情報は含めない）
- 予約データは必ず「済」「予定」「キャンセル」「無断」の4ステータスを混在させる（デモとして自然に見せるため）
- 全変更をコミットする（コミットメッセージ: `customize: 【サロン名】向けカスタマイズ`）
