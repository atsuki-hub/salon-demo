# 美容サロン 予約・経営ダッシュボード デモ 仕様書

## 0. 概要・スコープ

小規模美容サロン（スタイリスト2〜3名想定）向けの、予約管理＋経営ダッシュボードのデモ。

- 形態：静的Webアプリ（HTML/CSS/JS、サンプルデータ埋め込み、ログイン不要）
- 画面：(1) 予約管理画面（中スコープ）、(2) 経営ダッシュボード ← 主役
- 位置づけ：デモ用の参考実装。製品ではない。
- 納品時：実クライアント向けにはGAS＋スプレッドシートで作り直す。本仕様書のデータ構造がそのままGAS版のシート構造になる。

## 1. サンプルデータ構造

GAS納品版ではこの5シートがそのままスプレッドシートの構造になる。

### 1.1 予約テーブル（reservations）
1行 = 1来店。

| 列 | 型 | 説明 |
|---|---|---|
| 予約ID | 文字列 | 一意 |
| 日付 | 日付 | 来店日 |
| 開始時刻 | 時刻 | |

| スタイリストID | 文字列 | スタイリストマスタ参照 |

| 指名フラグ | 1 / 0 | 指名予約か否か |
| 技術売上 | 数値(円) | 施術の売上 |

| ステータス | 済 / キャンセル / 無断 | 集計対象は原則「済」のみ |

## 2. ダッシュボード指標定義

### 2.1 売上系

**M1 売上推移**
- 計算式：指定期間内の (技術売上 + 店販売上) 合計。日次・月次で集計。
- 対象：ステータス=済のみ。
- 表示：月次推移の折れ線＋当月数字＋前月比%。

**M2 客単価**
- 技術客単価 = 技術売上合計 ÷ 来店件数
- 総客単価 = (技術売上 + 店販売上) 合計 ÷ 来店件数
- 表示：数字カード2枚（技術／総）。
- メモ：美容では技術と店販を分けて見るのが基本。両方出す。

**M3 店販比率**
- 計算式：店販売上合計 ÷ 総売上。
- 表示：数字カード。
- メモ：サロンの利益率を左右する指標。

### 2.2 顧客・リピート系

**M4 新規／再来 構成**
- 計算式：期間内来店のうち、来店区分=新規 と 再来 の件数および構成比。
- 表示：数字カード＋ドーナツ。

**M5 新規客の90日定着率**（顧客系の核）
- 計算式：対象月に初来店した新規顧客のうち、初回来店日から90日以内に2回目の来店がある顧客の割合。
- 集計単位：初回来店月でグループ化して月別に算出。
- 表示：月別の定着率（バー or 折れ線）。
- メモ：最新3ヶ月は90日経過途中のため確定値にせず「集計中」表記とする。月次の単純リピート率より美容業態に正しくフィットする指標。

**M6 平均再来周期**
- 計算式：再来時の (今回来店日 − 同一顧客の前回来店日) の平均日数。
- 表示：数字カード（例：62日）。
- メモ：期間区切り不要。45日と90日では経営状態がまったく違う。

**M7 リピート率（累積・補助）**
- 計算式：全顧客のうち通算2回以上来店した顧客の割合。
- 表示：数字カード（補助扱い、小さめ）。
- メモ：累積のため鈍い指標。総合的な定着力の目安。主役はM5。

**M8 失客アラート（リスト）**
- 抽出：前回来店日から [閾値] 日を超えて来店がない顧客。
- 閾値の案：(a) 固定90日または120日、(b) その顧客の平均再来周期 × 1.5。← 要決定（4章）
- 表示：顧客リスト（氏名・前回来店日・経過日数・前回担当スタイリスト）。
- メモ：指標ではなくアクションリスト。

### 2.3 スタイリスト系

**M9 指名率**
- 計算式：指名フラグ=1 の予約数 ÷ 全予約数（ステータス=済）。サロン全体＋スタイリスト別。
- 表示：サロン全体の数字カード＋スタイリスト別バー。
- メモ：指名率の高いスタイリスト＝固定客を持つ＝サロンの資産。

**M10 スタイリスト別売上**
- 計算式：スタイリストごとの (技術売上 + 店販売上) 合計。
- 表示：スタイリスト別バー（ランキング）。

**M11 スタイリスト別客単価**
- 計算式：スタイリストごとの 売上 ÷ 担当来店件数。
- 表示：スタイリスト別バー。
- メモ：M9（指名率）と並べると「指名されるスタイリストは単価が高い」といった示唆が出る。

**M12 稼働率（席／スタイリスト）**
- 席稼働率（サロン全体）= 実施術時間合計 ÷ (席数 × 営業時間)
- スタイリスト稼働率（個人別）= 各スタイリストの実施術時間 ÷ 各スタイリストの勤務時間
- 表示：席稼働率は数字カード、スタイリスト稼働率はスタイリスト別バー。
- メモ：席とスタイリストは別物。両方持つと精度が高い。100%近い＝予約取りこぼし、低い＝余剰。

### 2.4 メニュー系

**M13 メニュー別売上構成**
- 計算式：メニューカテゴリ別の技術売上合計と構成比。
- 表示：カテゴリ別の構成比（ドーナツ or 積み上げ棒）。
- メモ：1予約=1主メニューモデルのため近似値（3章参照）。

**M14 メニュー別 時間あたり売上**（メニュー系の核）
- 計算式：メニュー（またはカテゴリ）別の 売上合計 ÷ 所要時間合計（円/時）。
- 表示：メニュー別バー（円/時）。
- メモ：美容経営の隠れ重要指標。カラーは単価高だが長時間、カットは低単価だが速い。"予約枠あたりいくら稼ぐメニューか"が分かり、予約の埋め方の判断に直結する。

## 3. 実務上の注意（設計判断）

- **1予約 = 1主メニュー モデル**：カット＋カラーの来店は主メニュー1つだけで計上する。メニュー別売上構成・件数（M13）は近似値になる。デモでは許容。本番納品では「会計明細テーブル」を別に持てば正確に出せる。
- **集計対象**：売上・客単価・稼働（M1〜M3, M9〜M14）は「ステータス=済」のみ。キャンセル・無断キャンセルは除外。キャンセル率を別カードで見せるのは任意。
- **最新月の未確定**：M5（90日定着率）は直近3ヶ月、M6（平均再来周期）も直近は値が固まらない。「集計中」表記を必ず入れる。
- **サンプルデータの期間**：M5を意味のある形で見せるには初回来店から90日の追跡期間が要る。サンプルは6ヶ月分を推奨（1ヶ月分ではM5・M6が成立しない）。
